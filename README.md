# screen-translate

画面の好きな範囲を OCR して、英語の文字を日本語の訳文に置き換えて見せる Windows 用の常駐アプリです。Google 翻訳の画像翻訳のように、訳文を元の文字の位置に重ねて表示します。翻訳には PLaMo 3 Translate 2B を使い、処理はすべてこの PC の中で完結します。

## 使い方

| キー | 動作 |
| --- | --- |
| Ctrl+Alt+T | 範囲を選び、1 回だけ翻訳する |
| Ctrl+Alt+R | 範囲を選び、リアルタイムで翻訳し続ける。もう一度押すと止まる |
| Ctrl+Alt+X | 翻訳を止めて訳文を消す |

範囲はドラッグで選びます。Esc か右クリックで取り消せます。

訳文は段落ごとに元の文字の上に重なり、背景色、文字色、太字は元の文字に合わせます。文字以外の部分はそのまま見えていて、数字やコードのように訳が変わらないものは置き換えません。1 回翻訳の訳文は、Ctrl+Alt+X を押すか次の範囲を選ぶまで残ります。

アプリを終了するには、タスクトレイのアイコンを右クリックして「終了」を選びます。

選択中も翻訳中もキーボードのフォーカスを取らないので、アクティブウィンドウは変わりません。クリックやスクロールは訳文を通り抜けて下の窓に届きます。

## 準備

Ollama と Rust が必要です。

```bash
ollama pull hf.co/pfnet/plamo-3-translate-2b-GGUF:Q4_K_M
```

```bash
cargo build --release
```

できた `target/release/screen-translate.exe` を起動します。

## 測定値

RTX 4070 Ti と Core i7-13700F の PC で測った値です。

| 項目 | 値 |
| --- | --- |
| 1 文の翻訳（範囲を決めてから表示まで） | 約 0.14 秒 |
| リアルタイムの更新（文字が変わってから表示まで） | 0.27〜0.35 秒 |
| 翻訳モデルが外れているときの初回 | 約 2.4 秒 |
| 1920×1080 の範囲 | 約 2 秒 |
| リアルタイムで文字が変わり続けるときの CPU 使用率 | PC 全体の約 4% |
| リアルタイムで画面が止まっているときの CPU 使用率 | PC 全体の約 0.01% |
| メモリ（待機中） | 9MB |
| メモリ（動作中） | 84MB |
| GPU メモリ（翻訳モデル） | 約 2GB |

OCR モデルは 60 秒使わないとメモリから外し、翻訳モデルは最後の翻訳から 5 分で Ollama が GPU メモリから外します。

## 構成

- 画面の取得は GDI の BitBlt で行います。文字が見えていれば、どのアプリの画面でも読めます。
- OCR は PP-OCRv6 small を rten で CPU 実行します。モデルは exe に埋め込んであるので、Python や DLL は要りません。
- 翻訳は Ollama の API に PFML3 形式のプロンプトを送ります。直前の 3 段落を翻訳履歴として渡すので、名前や用語の訳がそろいます。同じ段落の訳は再利用します。
- 重ね表示は透過色つきの最前面ウィンドウで、段落ごとに元の背景色で塗ってから訳文を描きます。訳文が長いときは、1 行なら右の空きへ広げ、それでも足りなければ文字を小さくします。
- リアルタイムでは 0.15 秒ごとに画面を見て、画素が変わったときだけ OCR を動かします。

## 制限

- 訳文はスクリーンショットや録画に写りません。OCR が自分の訳を読まないようにするためです。
- 写真やグラデーションの上の文字は、単色の四角で覆って置き換えます。
- 1 回翻訳の訳文は、下の画面が変わっても追従しません。追従させるにはリアルタイムを使います。
- 回転した文字は読めません。
- 長辺が 1,600 ピクセルを超える範囲は縮小してから読むので、小さい文字は読みにくくなります。
- 英語から日本語への翻訳だけに対応しています。
- 排他フルスクリーンのゲームと、拡大率の違う画面が混ざる環境では試していません。
